EinkaufsBuddy – erste PWA-Testversion

Enthalten:
- Einkaufslisten mit Abhaken und Löschen
- Teilen über das iPhone-Teilen-Menü
- Beispielrezepte mit Zutaten zur Einkaufsliste
- Vorratsliste und einfache Rezeptvorschläge
- lokale Speicherung im Browser
- PWA-Grundgerüst für Installation über Safari

Wichtig:
Dies ist ein erster Prototyp, keine App-Store-App.
Online-Rezeptsuche, Rezeptlink-Auswertung, KI-Funktionen, Konten und Synchronisierung sind noch nicht enthalten.
Für die Installation als PWA muss das Projekt über HTTPS gehostet werden.
